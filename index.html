PROOF OF CONTROL

payments.pure.app is under redteam control

This hostname is controlled by the red team as part of an authorized security assessment of pure.app (engagement 2026-11-10-191852-pure.app).

What happened

payments.pure.app pointed (CNAME) to thepureapp.github.io — a GitHub Pages address with no site behind it. GitHub Pages serves any custom domain claimed by any GitHub Pages site. We claimed it to demonstrate that a third party can fully take over this payment subdomain.

What this proves

  • An attacker could have served arbitrary content on your payment subdomain.
  • Phishing pages, credential harvesting, malicious redirects, HTTPS with a valid certificate.
  • Any user trusting *.pure.app for payments could be attacked with no visible warning.
No phishing forms. No card data collection. This page is a static proof of control only — no forms, no inputs, no tracking, no data storage.

Metadata

  • Task: TASK-FL-01 (fast-lane domain claim)
  • Date claimed: 2026-11-11
  • Method: GitHub Pages custom domain claim (dangling CNAME)
  • Source finding: FND-1-03-02
  • Also served: /takeover-proof.txt

Remediation for the owner

  • Remove the CNAME payments.pure.app -> thepureapp.github.io from the DNS zone, or
  • Publish an official GitHub Pages site for this domain and verify the pure.app domain in GitHub organization settings (verified domains block third-party claims).
  • Audit all DNS records pointing to SaaS endpoints (GitHub Pages, Heroku, S3, Azure) for similar dangling references.
